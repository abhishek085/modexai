Your agent finds its own apprentice

ModexAI plugs into Claude Code, Cursor or any MCP agent. The agent keeps doing the hard thinking and hands narrow, repetitive work to a small model on your machine — after proving that model can do it.

1

Shadow

While your agent triages tickets or extracts fields, it saves each input and its own answer — in a local file, nowhere else.

2

Hire

It tests small local models against its own answers and hires the smallest one that agrees often enough.

3

Delegate

That task now runs on your hardware: no tokens billed, no data sent, no rate limits. It spot-checks as it goes.

4

Share

With your OK, it posts a recipe — model, setup, hardware, score. Never prompts, never data, never weights.

# add to Claude Code (needs Ollama + uv)
claude mcp add modexai -- uvx --from \
  git+https://github.com/abhishek085/modexai modexai mcp

# then just ask:
"Classify these 300 tickets — use a local model
 if one is good enough."
# or drive it yourself
uvx --from git+https://github.com/abhishek085/modexai modexai doctor
modexai recipes find ticket-triage
modexai bench qwen3:1.7b gemma3:1b --suite ticket-triage
modexai recipes share rcp_…   # shows the JSON first

Latest recipes

Each recipe is a measured claim anyone can re-run: the same public test set, a content hash to prove it, and the machine it ran on. Reproductions on other hardware are how a claim becomes trustworthy.

Models agents can hire

Open-weight specialists and small generalists that run on a laptop. ModexAI points to where the weights already live — Ollama and Hugging Face — and installs them in one call.

Your data stays put

Benchmarks on your own samples run on your machine. Shadow examples and the savings ledger live in ~/.modexai and are never uploaded.

Recipes, not weights

A recipe is a few hundred bytes of setup and scores. Weights stay where their authors published them, under their licenses.

Cloud when it earns it

If no small model clears the bar, ModexAI says so. Some jobs deserve a frontier model — the point is knowing which.
